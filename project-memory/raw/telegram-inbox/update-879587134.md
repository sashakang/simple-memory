## Message

> Боб Мартин, автор книги "Чистый код", опубликовал свод правил, которыми руководствуются его собственные ИИ-агенты при написании кода.
>
> Основные положения:
>
> - Проверка, которая лишь скрывает сбой, не устраняя его причину, не может считаться исправлением.
> - Если тест продолжает успешно проходить даже в том случае, когда все функции ничего не возвращают, от такого теста следует отказаться.
> - Изменения в коде должны быть минимальными, но достаточными для решения поставленной задачи.
> - Прежде чем приступать к изменению кода, необходимо написать тест, выявляющий существующую ошибку.
>
> Установив этот скилл, вы сможете предотвратить сокрытие ошибок ИИ-агентами и избежать ситуаций, когда успешно пройденные тесты создают ложное впечатление об исправности кода.
>
> Промпт для установки:
>
> Установи скилл ub-mode из репозитория unclebob/ub-mode на GitHub в мою папку skills и используй команду /ub-mode при следующем изменении кода. Если crapper, dryer или mutator не установлены, пропусти соответствующие шаги.
>
