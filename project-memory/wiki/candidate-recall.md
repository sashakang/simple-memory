# candidate: Recall

- **Site:** https://www.recall.it · **Level:** 5 (self-organizing KB), hosted variant — in [[concept-six-levels-of-memory]]
- **Source:** [[source-every-cc-memory-system-compared]]

A **hosted** "Karpathy LLM Wiki done for you": browser extension saves articles/podcasts/PDFs; Recall
summarizes, tags, and auto-builds the knowledge graph. Own AI chat over your saved content, mobile, MCP access
so Claude Code can query it. Zero setup, no Obsidian needed.

**Against our constraints:** **fails (c) local-first** — data is live on Recall's servers (export-to-markdown
exists, but you're renting while live). The source also flags it as **consumption-oriented, not operational**
("which video mentioned memory?" vs "what did we decide about client X in March?"), plus a pricing implication.
Good for non-technical content organizing; wrong shape for our operational-memory charter.
